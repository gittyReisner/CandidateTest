AI Usage

AI tools were used as a supporting tool during the development of this assessment.

1. AI Tools Used
ChatGPT
GitHub Copilot
2. Stages Where AI Was Used

AI was used as a supporting tool during:

Planning
Implementation
Debugging
Testing
Architecture design
Cloud planning
Documentation

AI was mainly used to discuss possible approaches, help with questions that came up during development, and review parts of the solution.

GitHub Copilot was used to assist in generating unit tests and improving logic.

3. Changes Made to AI Suggestions

AI suggestions were not followed automatically.

For example, some suggestions included adding more functionality or complexity than was required for the assessment. I chose to keep the implementation focused on the requested requirements and avoid unnecessary changes.

I also chose to organize the frontend into separate components instead of keeping all the UI logic in a single file. This made the code easier to read, maintain and understand.

The final decisions were based on the project requirements, the existing project structure, and what I considered clear and practical to implement.

4. Rejected Suggestions

Some suggestions were rejected when they were more complex than necessary or were not required for the assessment.

For example, I chose not to add additional functionality that was not part of the requested feature, in order to keep the solution simple and focused.

5. Verification

The solution was verified by:

Building the backend and frontend successfully.
Running the backend unit tests.
Testing the API manually through Swagger.
Testing the frontend in the browser.
Checking the main filtering, sorting and pagination scenarios.
Checking loading, error and no-results states.
Reviewing the architecture and cloud diagrams against the assessment requirements.

The final implementation was reviewed to make sure I understood the code and the decisions made in the solution.
